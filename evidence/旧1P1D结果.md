性能、排队、命中及占用沿用原配比实验。活跃主 KV 与重复指标取自独立块级回放。每组 P Store 192 GiB、c16、D 调度上限 32，冻结 W2 共 985 个请求。

按 D 物理块统计，重复比例为重复主 KV 字节的时间积分除以活跃主 KV 字节的时间积分。全局 Store 取 P 与 D 对象并集，按内容哈希与 D 块匹配。Store 约每 5 秒采样，解码新增 KV 采用插值。

全 workload 按请求累计 82,229,306 个主 KV token 位置。每个位置在该请求解码期间任一快照匹配即计一次，共享前缀按请求分别计。仅计完整的 128-token 块。各组 11–19 条短请求未落入有效快照，仍进入分母。

总预算为 P Store、D Store 和 D sparse 配额之和。吞吐为整轮输出 tokens/s。TTFT 为首 token 延迟，P95 为第 95 百分位。TPOT 为首 token 后每个输出 token 的平均耗时。P、D 排队按平均等待请求数统计，D 记录容量等待。P 前缀命中合计本地和外部 token 命中。
